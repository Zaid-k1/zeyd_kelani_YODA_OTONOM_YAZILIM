# zeyd_kelani_YODA_OTONOM_YAZILIM

## Git Nedir?
Git, yazılım geliştirmede sürüm kontrol sistemi (Version control system) olarak kullanılan bir araçtır. Kodlardaki değişiklikleri kaydeder ve onlara geri dönülebilmesini sağlar. Ayrıca birden fazla kişinin birlikte aynı proje üzerinde birbirleriyle çakışmadan çalışmalarını sağlar.

## GitHub Nedir?

GitHub, Git tabanlı projelerin saklandığı ve paylaşıldığı çevrim içi bir platformdur. Kodları bulutta saklar, isteğe bağlı paylaşır ve takım çalışması veya iş birliği yapmayı sağlar.

## Git, GitHub Temel Kavramları

Repository: Bir projenin klasörüdür. Burada projenin tüm kodları, dokümantasyonları ve değişiklik kayıtları bulunur. Her repo'nun genellikle bir README dosyası bulunur. Bu dosya genelde projenin tanımı ve proje hakkında genel bilgiler içerir.
commit: Bir projedeki değişiklikleri kaydetmeye yarayan Git komutu. Örnek:  git commit -m "Açıklama" 
log: Bir dosyaya yapılan tüm kaydetmeleri kaydetme işleminin yapıldığı tarih, saat ve commit yaparken belirtilen açıklama ile birlikte gösteren git komutu. (git log)
branch: Bir projenin main, yani ana dalını bozmadan yeni bir dal oluşturarak proje üzerinde çalışılmasını, değişiklikler yapılmasını sağlar. git checkout -b branchAdı komutu ile git'ten yeni bir branch oluşturulabilir.
merge: İki branch'ın birbirleriyle birleştirilmesini sağlayan işlem.
push: git'te oluşturulan dosyaları ya da genel olarak git'ten yapılan tüm değişikliklerin github'a aktarılmasını sağlayan işlem.
pull: GitHub'da yapılan işlemlerin git'e aktarılmasını sağlayan işlem.
